<div align="center">
    <h1>git-copy-branch-name</h1>
</div>

`git-copy-branch-name` is a command-line tool that simply copies the name of the current branch into your clipboard history.

## Installation

### Homebrew (macOS/Linux)

You can install `git-copy-branch-name` using Homebrew:

```bash
brew install jop-software/tap/git-copy-branch-name
```

### Manual

1. clone this repository
   ```bash
   git clone git@github.com:jop-software/git-copy-branch-name.git
   ```
2. navigate to the project directory
   ```bash
   cd git-copy-branch-name
   ```
3. Add the `bin/` directory to your PATH or move the `git-copy-branch-name` script to a directory that is already in your PATH, e.g., `/usr/local/bin/`

## Usage

```bash
git copy-branch-name
```
